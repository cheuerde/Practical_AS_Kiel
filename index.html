Advanced Statistics Lab

Animal breeding masters program, Kiel University

This is the new Quarto home for the Advanced Statistics lab. The goal is a course format that works in class, on student laptops, and later as a reproducible reference.

The old R Markdown chapters are still present under chapters/. New material will move into two connected forms:

  • labs/: student-facing notes with runnable code and exercises.
  • lectures/: RevealJS slides for projection during class.

2 Suggested Class Workflow

Use the slides in a browser for projection, with RStudio open on the matching lab file. Run selected chunks live in RStudio when the class should see the code execute, and let students run the same chunks locally.

This keeps the projected material clean while avoiding copy-paste between windows.

The theme dropdown at the top changes the visual theme live on both lab pages and slides. The t key cycles through the same themes during presentation.

3 Local Setup

Install R, RStudio, Git, and Quarto before class. Then clone or download this repository and run the package setup from the repository root.

3.1 Install R And RStudio

Platform R RStudio Extra tools for brms/Stan
Windows Install R from CRAN. Install RStudio Desktop from Posit. Install Rtools.
macOS Install R from CRAN or with brew install r. Install RStudio Desktop from Posit or with brew install --cask rstudio. Run xcode-select --install.
Ubuntu/Debian Linux Run sudo apt update && sudo apt install r-base r-base-dev. Download the Ubuntu/Debian .deb from Posit and install it with sudo apt install ./rstudio-*.deb. Run sudo apt install build-essential gfortran libcurl4-openssl-dev libssl-dev libxml2-dev.
Fedora/RHEL Linux Run sudo dnf install R. Download the Fedora/RHEL .rpm from Posit and install it with sudo dnf install ./rstudio-*.rpm. Run sudo dnf install gcc gcc-c++ gcc-gfortran make libcurl-devel openssl-devel libxml2-devel.

Quarto is needed to render the website locally. Install it from quarto.org. On macOS with Homebrew, this is:

brew install --cask quarto

On Linux, the Quarto download page provides .deb and .rpm installers. On Windows, use the .msi installer.

3.2 Install Git

Git is needed for the recommended course setup because it lets students clone the repository and later pull updates.

Platform Git install
Windows Install Git for Windows. The default installer options are fine.
macOS Run xcode-select --install or install Git with Homebrew: brew install git.
Ubuntu/Debian Linux Run sudo apt update && sudo apt install git.
Fedora/RHEL Linux Run sudo dnf install git.

After installation, check that Git is available:

git --version

3.3 Get The Course Repository

git clone https://github.com/cheuerde/Practical_AS_Kiel.git
cd Practical_AS_Kiel

If you downloaded a ZIP file instead, open a terminal in the extracted Practical_AS_Kiel folder.

3.4 Install R Packages

Minimal packages for the R introduction and the website:

Rscript setup/install.R --minimal
Rscript setup/check.R --minimal

Applied course packages for the main labs:

Rscript setup/install.R
Rscript setup/check.R

This installs the core/applied package set used by the course material:

dlookr, ggplot2, knitr, rmarkdown,
BGLR, data.table, DT, lattice, Matrix, mvtnorm, plotly, rrBLUP, tidyverse

Bayesian modelling with brms and Stan:

Rscript setup/install.R --stan --install-cmdstan
Rscript setup/check.R --stan

This adds:

bayesplot, brms, cmdstanr, posterior

Full dependency installation, including the original Stan/JAGS/clustering support packages and CmdStan, is mostly useful for the instructor machine or for students who want to run every optional block.

Before running --all, install the platform tools above first. The archived JAGS example also needs JAGS itself before rjags can be installed. JAGS is not needed for the live brms/CmdStan workflow.

Platform JAGS install
Windows Install JAGS 4.x from the JAGS project page.
macOS Run brew install jags.
Ubuntu/Debian Linux Run sudo apt install jags.
Fedora/RHEL Linux Run sudo dnf install JAGS. 
Rscript setup/install.R --all
Rscript setup/check.R --all

The legacy and optional package set is:

car, ellipse, emmeans, factoextra, GGally, htmltools, klippy, lsmeans, lubridate,
mixtools, pacman, pander, pedigreemm, prettydoc,
remotes, rjags, rmdformats, rstan
