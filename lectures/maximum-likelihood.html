Definition

Optimization asked:

\[ \widehat{\theta} = \operatorname*{arg\,min}_{\theta} f(\theta) \]

Maximum likelihood chooses \(f(\theta)\) from a probability model.

Likelihood And Log-Likelihood

For independent observations:

\[ L(\theta; \mathbf{y}) = \prod_{i=1}^{n} p(y_i \mid \theta) \]

\[ \log L(\theta; \mathbf{y}) = \sum_{i=1}^{n} \log p(y_i \mid \theta) \]

In R

optim() minimizes.

So we return the negative log-likelihood:

\[ -\sum_{i=1}^{n} \log p(y_i \mid \theta) \]

\[ f(y) = \frac{1}{\sigma \sqrt{2\pi}} \exp\left[-\frac{1}{2}\left(\frac{y - \mu}{\sigma}\right)^2\right] \]

Finding Mean And Standard Deviation

sdlik <- function(x) {
  res <- 0
  if (x > 0) res = 1
  return(log(res))
}

lik <- function(par, y) {
  mean = par[1]
  sd = par[2]

  L2 <- sdlik(sd)
  if (!is.finite(L2)) return(Inf)

  L1 <- dnorm(x = y, mean = mean, sd = sd, log = TRUE)
  return(-sum(L1 + L2))
}

Estimating Correlation

library(mvtnorm)

corlik <- function(x) {
  res <- 0
  if (x >= -1 & x <= 1) res = 1
  return(log(res))
}

varlik <- function(x) {
  res <- 0
  if (x > 0) res = 1
  return(log(res))
}

Build Sigma

lik <- function(par, y) {
  L2 <- corlik(par[5])
  L3 <- varlik(par[3])
  L4 <- varlik(par[4])
  if (!all(is.finite(c(L2, L3, L4)))) return(Inf)

  covAB <- par[5] * (sqrt(par[3]) * sqrt(par[4]))
  sigma <- array(c(par[3], covAB, covAB, par[4]), dim = c(2, 2))

  L1 <- tryCatch(
    dmvnorm(x = y, mean = c(par[1], par[2]), sigma = sigma, log = TRUE),
    error = function(e) -Inf
  )
  if (!all(is.finite(L1))) return(Inf)

  return(-sum(L1 + L2 + L3 + L4))
}

Animal Likelihood Function

lik <- function(par, y, X, A) {
  L2 <- varlik(par[1])
  L3 <- varlik(par[2])
  if (!all(is.finite(c(L2, L3)))) return(Inf)

  b <- matrix(c(par[3:(2 + ncol(X))]), ncol = 1)
  G <- A * par[2]
  R <- diag(length(y)) * par[1]
  V <- G + R
  mu <- X %*% b

  L1 <- tryCatch(
    dmvnorm(x = y, mean = as.numeric(mu), sigma = V, log = TRUE),
    error = function(e) -Inf
  )
  if (!all(is.finite(L1))) return(Inf)

  return(-sum(L1 + L2 + L3))
}

Take-Home

Maximum likelihood is not a new algorithm.

It is an optimization problem where the objective comes from a probability model.

The code pattern is:

  1. collect unknowns in p,
  2. build the likelihood in lik(),
  3. run optim(p, lik, ...).

Exercises

  1. Change starting values in p.
  2. Estimate mu and sigma with n = 20.
  3. Change the true value of rho.
  4. Change the relationship matrix A.
